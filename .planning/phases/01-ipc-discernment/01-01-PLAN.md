<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser -> Laravel dispatch | Untrusted task text, images, and arbitrary extra fields cross into the application. |
| Laravel controller -> local IPC files | Server-owned classification and serialized payloads control the Node watcher. |
| Laravel -> broadcast/UI | Persisted response text becomes visible to browser subscribers. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-01 | Spoofing | dispatch mode selection | high | mitigate | Derive mode only from the server-side classifier; ignore client routing fields. |
| T-01-02 | Tampering | task queue and pending payload | high | mitigate | Branch before IPC writes and preserve server-built actionable payload fields. |
| T-01-03 | Repudiation | dispatch logging/message history | medium | accept | Retain existing Laravel persistence/logging conventions; new scope does not add identity or audit infrastructure. |
| T-01-04 | Information disclosure | casual response and task text | medium | mitigate | Preserve encoded framework broadcast/database path and avoid echoing untrusted control data in response templates. |
| T-01-05 | Denial of service | task and image validation/classification | medium | mitigate | Apply `TASK_TEXT_MAX_LENGTH = 10,000`, maximum 5 images, bounded-memory decoding with 5 MiB per decoded image and 20 MiB aggregate decoded image bytes, then permit storage/IPC only after checks pass; use deterministic matching without model/process calls. |
| T-01-06 | Elevation of privilege | casual workflow bypass | high | mitigate | Fail closed to actionable for all non-greeting, mixed, and attachment-bearing input. |
</threat_model>
