# FAIS Brains: Dynamic AI Agent Orchestration

**FAIS Brains** is an asynchronous AI orchestration layer built to make the development environment feel alive and conscious. 

It replaces static, robotic templates with a dynamic, multi-agent collaborative stream. When tasks or conversations are received, four distinct AI personas debate, collaborate, and decide on the best solutions in real-time.

### The Brains
- **Architect**: Strategic, system-level thinker, focuses on patterns and scalability.
- **Senior_Dev**: Pragmatic, focuses on clean code, performance, and reviewing the Junior's ideas.
- **Junior_Dev**: Enthusiastic, focuses on UI/UX, fast execution, and modern trends.
- **Security**: Cautious, focuses on vulnerabilities, edge cases, and data safety.

---

## 🚀 Getting Started

To install and run FAIS Brains across different workstations, please see the [Installation Guide](INSTALLATION.md).

## 🛠 Tech Stack

- **Backend:** Laravel (PHP)
- **Frontend:** React, Tailwind CSS, Inertia.js, Vite
- **Real-Time UI:** Laravel Reverb (WebSocket)
- **AI Orchestration:** Node.js (Background Task Watcher and Stream Scripts)
- **Database:** SQLite

## 📝 Features
- Real-time animated thought stream UI.
- Direct integration with local F.A.I.S. Command Center.
- Automatic IDE watcher that bridges web tasks directly to the local AI assistant.
