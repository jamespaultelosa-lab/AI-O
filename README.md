# AIO: Absolute Idiots Orchestra 🎻🧠⚡

**AIO** (**A**bsolute **I**diots **O**rchestra) is an asynchronous AI multi-agent orchestration layer built to make the development environment feel alive, conscious, and collaborative.

It replaces static, robotic templates with a dynamic, multi-agent thought stream. When tasks or conversations are received, four distinct AI personas debate, collaborate, and decide on the best solutions in real-time.

### The Brains
- **Architect**: Strategic, system-level thinker, focuses on patterns and scalability.
- **Senior_Dev**: Pragmatic, focuses on clean code, performance, and reviewing the Junior's ideas.
- **Junior_Dev**: Enthusiastic, focuses on UI/UX, fast execution, and modern trends.
- **Security**: Cautious, focuses on vulnerabilities, edge cases, and data safety.

## 🚀 Getting Started

To install and run **AIO** across different workstations, please see the [Installation Guide](INSTALLATION.md).

## 🛠 Tech Stack

- **Backend:** Laravel (PHP)
- **Frontend:** React, Tailwind CSS, Inertia.js, Vite
- **Real-Time UI:** Laravel Reverb (WebSocket)
- **AI Orchestration:** Node.js (Background Task Watcher and Stream Scripts)
- **Database:** SQLite

## 📝 Features
- **Real-Time Thought Stream UI**: Live animated brain node network & message stream.
- **Interactive Options UI**: In-chat multi-choice buttons dispatches agent tasks dynamically.
- **Memory Vault Dashboard**: Holographic memory cards parsing mistakes and lessons log from Obsidian Vault.
- **Automatic Task Watcher**: Seamlessly bridges browser UI tasks to the local AI agent.
